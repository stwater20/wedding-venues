☁️ 兩人同步設定

收藏、狀態、備註、自訂飯店會存到 GitHub repo 的 state.json。你和另一半各自在自己的裝置上填一次 Token，之後改動就會自動同步（最後儲存者為準）。Token 只存在這台裝置的瀏覽器裡。
